Questions

Before you buy.

Do I need to know Next.js?

No. You edit TypeScript files that read like a form: names, dates, descriptions. The guides walk through every file. Knowing React helps if you want to change layouts.

Do I need a server or database?

No. The site builds to static files. The resume and social images are generated at build time, and the contact form posts to a form service or opens the visitor's email app.

Where can I host it?

GitHub Pages for free with the included workflow, or Vercel, Netlify, Cloudflare Pages and any static host.

Is the sample content real?

No. The sample developer, companies and figures are fictional, so you can see the layout with realistic content. There are no fake testimonials anywhere.
